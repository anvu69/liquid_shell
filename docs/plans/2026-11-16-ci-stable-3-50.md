> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The workspace resolves on Flutter 3.44.x, 3.47.9 and stable 3.50.0; `checks (stable)`, `goldens (stable)` and the SDK half of `pana` turn green; the generated channel code and the floor do not change.

A small `tool/check_analyze.dart` turns the two known 3.50-only info classes (R1, R2) into printed, tolerated issues on the stable leg only. The blocking `pana` job is pinned to 3.47.9, with an informational stable twin. Spec: `docs/specs/2026-11-16-ci-stable-3-50-design.md`. Evidence: `.superpowers/sdd/vk1076-design.md` (vankhan ledger dir, untracked, not in this worktree).

**Tech Stack:** fvm (3.44.9, 3.47.9, 3.50.0), Pigeon 27.3.0, `package:test`, GNU make, GitHub Actions, pana.

## Global Constraints

- Every published pubspec keeps its SDK constraints; only `liquid_shell_ios` loses its `pigeon` dev dependency. No CHANGELOG change (nothing changes for users).
